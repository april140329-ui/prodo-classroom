# 프로도와 친구들 교실

가족 놀이용 가상 초등 교실 PWA입니다. 가족용 `family-today-14077` Firebase 프로젝트를 재사용하되, 수업 기록은 `classrooms/prodo` 경로에 분리해 저장합니다. 가족 할 일 데이터(`families/home`)는 앱에서 읽거나 변경하지 않습니다.

## 접근 보호
- Google 로그인 필수, 이메일 인증이 끝난 기존 가족 허용 계정만 접속할 수 있습니다.
- Firestore rules는 기존 `families/home` 규칙을 유지하고 `classrooms/prodo/**`에만 같은 가족 허용 규칙을 추가합니다. 나머지는 모두 거부합니다.
- 프런트엔드 저장소는 공개일 수 있으나, 수업 알림장과 점수는 비공개 Firestore 문서입니다. 브라우저 화면의 로그인 검사는 편의 기능이고, 실제 차단은 Firestore 규칙이 담당합니다.
- Google 로그인 도메인은 기존 가족 사이트와 같은 `april140329-ui.github.io`를 사용합니다.

## 기능
가상 학생 8명, 초2 눈높이로 새로 작성한 국어·수학·통합 수업 활동, 쪽지시험, 가족 동기화 알림장·점수, 당번·발표 순서·주사위·쉬는 시간 타이머, EBS 초등 공식 링크, 모바일 홈 화면 설치(PWA).

## 배포 확인
앱은 개인·가족 데이터, 비밀번호, 토큰, 암호키를 저장소에 포함하지 않습니다. Firebase 웹 앱 설정의 API key는 웹 SDK 식별 설정이며 비밀키가 아닙니다. 접근 보호는 Firestore rules와 Google 로그인 허용 계정에서 합니다. 규칙을 콘솔에 게시하기 전에 기존 규칙과 비교하고, 비로그인·허용되지 않은 계정의 읽기/쓰기가 거부되는지 확인합니다.
